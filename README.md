# متجر إلكتروني

تطبيق Flutter للتسجيل والدخول، استعراض الأقسام والمنتجات، إدارة السلة، وإنشاء
الطلبات ومراجعتها. يتصل التطبيق بواجهات API على `127.0.0.1:8000`.

## تشغيل التطبيق

- شغّل خادم الـ API على المنفذ `8000`.
- شغّل التطبيق باستخدام `flutter run`.
- يستخدم Android Emulator العنوان `10.0.2.2` للوصول إلى خادم الجهاز المضيف.
- لتحديد عنوان مختلف (مثل جهاز حقيقي على الشبكة)، مرّر
  `--dart-define=API_BASE_URL=http://192.168.1.10:8000/` إلى Flutter.

تُرسل طلبات GET قيمة `If-None-Match` عند توفر `ETag` سابق. عند رد الخادم
بـ `304 Not Modified` يحتفظ التطبيق بالبيانات الحالية ولا يعيد تحميل قائمة
التصنيفات أو المنتجات. يعتمد التطبيق body لكل استجابة `200` حتى لو بقيت قيمة
`ETag` كما هي؛ على الخادم إرجاع `304 Not Modified` فقط عندما يكون المحتوى لم
يتغير فعلًا.
